# Birthday site

Статический мобильный сайт-поздравление для GitHub Pages.

## Публикация

1. Загрузи содержимое этой папки в корень репозитория.
2. GitHub → Settings → Pages.
3. Source: `Deploy from a branch`.
4. Branch: `main`, folder: `/(root)`.
5. Открой адрес вида `https://USERNAME.github.io/REPOSITORY/`.

## Отправка ответов

В конце сайта кнопка **«Отправить ответы»** использует системное меню `Поделиться` (`Web Share API`). На телефоне пользователь выбирает Telegram и нужный чат самостоятельно. Сервер, Telegram-бот, токен и база данных для этого не нужны.

Если браузер не поддерживает системное меню, сайт попробует открыть стандартное Telegram-меню «Поделиться». Последний fallback — копирование ответов в буфер обмена.

Для Web Share лучше открывать сайт по HTTPS — GitHub Pages как раз работает через HTTPS.
