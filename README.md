# Birthday site

Интерактивное поздравление с днём рождения.

## Что уже работает

- мобильный полноэкранный дизайн;
- первый шуточный вопрос «Когда у тебя день рождения?»;
- валидация и форматирование даты;
- реплика «Молодец, что указала. А то я сам не знал просто.»;
- плавные переходы между сценами;
- интерактивный выбор ответа;
- анимированный счётчик;
- частицы и анимация подарка;
- адаптив под телефон и desktop.

## Запуск локально

Никакой сборки не нужно. Можно просто открыть `index.html` или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## GitHub Pages

Проект намеренно статический (`index.html`, `styles.css`, `script.js`), поэтому может публиковаться прямо из ветки через GitHub Pages без npm/build шага.
